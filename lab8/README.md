# Сайт рекламного агентства

Веб-приложение для рекламного агентства, реализующее MVP (Minimum Viable Product) с функционалом каталога услуг, портфолио проектов, калькулятора стоимости и форм обратной связи.

## Описание проекта

Сайт рекламного агентства представляет собой современное одностраничное приложение (SPA), построенное на React и TypeScript. Проект включает:

- **Главную страницу** с герой-секцией, ключевыми услугами, преимуществами и формой обратной связи
- **Каталог услуг** с детальными страницами и калькулятором стоимости
- **Портфолио проектов** с интерактивными карточками кейсов
- **Формы обратной связи** с валидацией и сохранением в localStorage
- **Адаптивный дизайн** для устройств от 320px до 1920px

## Установка и запуск


### Установка зависимостей

```bash
# Установка зависимостей для ui-library
cd lab7/ui-library
npm install

# Установка зависимостей для website
cd ../website
npm install
```

### Запуск в режиме разработки

```bash
# Запуск website
cd lab7/website
npm run dev

# Приложение будет доступно по адресу http://localhost:5173
```

### Сборка проекта

```bash
# Сборка ui-library
cd lab7/ui-library
npm run build

# Сборка website
cd ../website
npm run build
```

## Доступные команды

### Для обоих проектов (ui-library и website):

## Основные функции

### Главная страница
- Герой-секция с ключевым предложением
- Блок "Ключевые услуги" (первые 3 услуги)
- Блок "Преимущества агентства"
- Блок "Отзывы клиентов" (слайдер)
- Форма обратной связи

### Каталог услуг
- Отображение услуг в виде карточек
- Страница детального просмотра услуги
- Интерактивный калькулятор стоимости услуг

### Портфолио
- Сетка карточек проектов
- Модальные окна с детальной информацией
- Слайдер изображений для проектов

### Формы обратной связи
- Валидация полей (имя, email, телефон, сообщение)
- Сохранение заявок в localStorage
- Отображение сообщений об успешной отправке
