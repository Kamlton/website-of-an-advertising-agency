# Функциональные требования MVP: Сайт рекламного агентства

## Основные модули системы
### Модуль "Главная страница и навигация"
```
1. Система должна отображать главную страницу с герой-секцией, содержащей ключевое предложение агентства
2. Система должна предоставлять навигационное меню с разделами: "Главная", "Услуги", "Портфолио", "О нас", "Контакты"
3. Система должна обеспечивать адаптивное отображение контента для устройств с шириной экрана от 320px до 1920px
4. Система должна отображать контактные данные и кнопку "Получить консультацию" в шапке сайта
```
### Модуль "Каталог услуг"
```
1. Система должна отображать каталог услуг в виде карточек, каждая из которых содержит: название, иконку, краткое описание и кнопку "Подробнее"
2. Система должна предоставлять страницу детального просмотра услуги с полным описанием, процессом работы, тарифами и формой заказа
3. Система должна предоставлять интерактивный калькулятор стоимости услуг
```
### Модуль "Портфолио проектов"
```
1. Система должна отображать портфолио в виде сетки карточек проектов
3. Каждая карточка проекта должна содержать: название, изображение, тип услуги, краткие результаты
```
### Модуль "Взаимодействие с клиентом"
```
1. Система должна предоставлять форму обратной связи с полями: "Имя", "Телефон", "Email", "Сообщение"
2. Система должна предоставлять форму быстрой заявки на консультацию
3. Система должна валидировать вводимые данные (формат email, номер телефона)
4. Система должна сохранять заявки в локальном хранилище браузера
```
## Use Case: Просмотр главной страницы
#### Участники: Пользователь, Система отображения контента

#### Предусловия:
```
•Пользователь зашел на главную страницу
•Система загрузила основной контент
```
#### Основной сценарий:
```
1. Пользователь переходит на главную страницу
2. Система показывает герой-секцию с основным предложением
3. Пользователь листает страницу вниз
4. Система отображает блок "Ключевые услуги"
5. Пользователь знакомится с услугами
6. Система показывает блок "Преимущества агентства"
7. Пользователь просматривает преимущества в цифрах
8. Система отображает блок "Портфолио"
9. Пользователь просматривает лучшие кейсы
10. Система показывает форму обратной связи
11. Пользователь заполняет и отправляет заявку (опционально)
```
#### Результат: Пользователь ознакомился с услугами агентства и может оставить заявку

#### Альтернативный сценарий:
```
1. При ошибке загрузки система показывает страницу 404
2. Пользователь обновляет страницу для повторной попытки
```
## Use Case: Расчет стоимости услуги через калькулятор
#### Участники: Пользователь, Система расчета стоимости

#### Предусловия:
```
•Пользователь находится на странице "Услуги"
•Система загрузила калькулятор стоимости
```
#### Основной сценарий:
```
1. Пользователь выбирает тип услуги из dropdown-меню
2. Система показывает дополнительные параметры для выбранной услуги
3. Пользователь указывает бюджет рекламной кампании
4. Пользователь выбирает дополнительные опции (если применимо)
5. Система в реальном времени пересчитывает и отображает ориентировочную стоимость
6. Пользователь нажимает кнопку "Получить точный расчет"
7. Система открывает модальное окно с формой для контактов
8. Пользователь заполняет форму (имя, телефон, email)
9. Пользователь нажимает кнопку "Отправить"
10. Система проверяет корректность заполнения полей
11. Система сохраняет заявку в localStorage
12. Система показывает сообщение об успешно отправленной заявке
```
#### Результат: Пользователь получил расчет стоимости и отправил заявку на консультацию

#### Альтернативный сценарий:
```
1. Система обнаруживает, что поле "Телефон" заполнено некорректно
2. Система подсвечивает поле красным и показывает сообщение об ошибке
3. Пользователь исправляет номер телефона
4. Возврат к шагу 9
```
